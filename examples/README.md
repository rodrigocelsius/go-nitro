# Examples

Runnable apps for Nitro v1. All live under [`v1/`](v1/).

## Happy path (CLI)

```bash
nitrogen new shop --module github.com/acme/shop
cd shop
nitrogen install sqlite   # or postgresql — then: nitrogen up
nitrogen make:scaffold Product name:string price:float64 active:bool --resource
nitrogen up
```
