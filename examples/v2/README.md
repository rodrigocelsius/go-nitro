# Examples (v2)

Runnable, tested apps for the main Nitro v2 routines. Each folder is its own module (local `replace` to this checkout); `go test .` needs no Docker (SQLite in memory).

| Example | Shows |
|---------|-------|
| [`resource-crud`](resource-crud/) | `app.Resource` + BLinq: filters, sort, pagination, PATCH merge, soft delete, computed fields, dashboard counters |
| [`transactions`](transactions/) | Sale + items + stock in one transaction, paid bill → customer status, `BeforeDelete` veto, `InTxRetry`, `AfterCommit` |
| [`business-commands`](business-commands/) | `Commands` / `Rules` / `Queries`, `Roles().When()`, JWT by default, audit row in the same transaction |
| [`queue`](queue/) | `nitro.QueueFromEnv` (memory / RabbitMQ / NATS / Kafka), publish after COMMIT, retries |
| [`cache`](cache/) | In-process cache, shared Redis read-through across replicas, Redis outage |
| [`cli-shop`](cli-shop/) | App generated by `nitrogen new` → `install sqlite` → `make:scaffold` (Clean Architecture) + a transactional use case with a `UnitOfWork` port |

```bash
for d in examples/v2/*/; do (cd $d && go test ./...); done
```
